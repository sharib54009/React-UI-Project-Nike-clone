# Nike Clone 👟

This is a **Nike website clone** that I built using React.js as a frontend project.

I created this project to improve my understanding of React and get more hands-on experience with building a real-world website from scratch. I tried to recreate the look and feel of a Nike website while keeping the code organized and reusable.

## Tech Used

* React.js
* JavaScript
* HTML
* CSS
* Vite

## What I Learned

While building this project, I got more comfortable with:

* Creating reusable React components
* Managing UI using React
* Working with props and state
* Structuring a React project
* Making websites responsive
* Building modern website layouts
* Improving my frontend development skills

## Running the Project

Clone the repository:

```bash
git clone https://github.com/your-username/nike-clone.git
```

Go into the project folder:

```bash
cd nike-clone
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
